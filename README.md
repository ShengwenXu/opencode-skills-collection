# OpenCode Skills

## 安装命令 / Installation

### macOS

```sh
curl -fsSL https://raw.githubusercontent.com/ShengwenXu/opencode-skills-collection/main/install.sh | bash
```

### Windows PowerShell

```powershell
irm https://raw.githubusercontent.com/ShengwenXu/opencode-skills-collection/main/install.ps1 | iex
```
